OBS: esta página serve como um guia rápido (tipo um mini-Swagger). Para executar as requisições corretamente (principalmente o fluxo de autenticação e uso de token), use o Postman importando a collection do projeto.

🚀 Endpoints Principais

Autenticação

POST /auth/registrar - Registra usuário
POST /auth/login - Faz login (retorna token JWT)

Filmes

GET /filmes - Lista todos os filmes (paginação e filtros)
GET /filmes/{id} - Busca filme por ID
POST /filmes - Cria novo filme 🔒
PUT /filmes/{id} - Atualiza filme completo 🔒
PATCH /filmes/{id} - Atualiza filme parcial 🔒
DELETE /filmes/{id} - Remove filme 🔒

Exemplos de filtros:

  • ?pagina=0&tamanho=10 (paginação)
  • ?titulo=matrix
  • ?generoId=1
  • ?diretor=nolan

Gêneros

Referência rápida (para usar em generoId):

  • 1 - "Ação"
  • 2 - "Comédia"
  • 3 - "Drama"
  • 4 - "Ficção Científica"
  • 5 - "Terror"
  • 6 - "Romance"
  • 7 - "Suspense"
  • 8 - "Animação"
  • 9 - "Documentário"
  • 10 - "Aventura"
GET /generos - Lista todos os gêneros
GET /generos/{id} - Busca gênero por ID
GET /generos/{id}/filmes - Lista filmes do gênero
POST /generos - Cria novo gênero 🔒
PUT /generos/{id} - Atualiza gênero 🔒
DELETE /generos/{id} - Remove gênero 🔒
